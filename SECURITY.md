## 2. Reporting a Vulnerability

**DO NOT file public GitHub issues for security vulnerabilities.**

If you discover a security vulnerability, token leakage, or critical weakness in HYDRA TOKENS ANTIGRAVITY:
1. Email your findings confidentially to: **`maijor.mesquita@gmail.com`**
2. Include:
   - Description of the vulnerability
   - Steps to reproduce / proof-of-concept
   - Impact assessment
3. You will receive an initial response within 48 hours.
4. Coordinated public disclosure will take place after a fix has been released.
